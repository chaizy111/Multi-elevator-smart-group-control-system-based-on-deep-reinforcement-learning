# 第二轮对照的设计与保存方式

此目录只供历史对照，不在当前默认Python路径或页面索引中。当前首版PPO的训练、奖励和推理未改变。

固定规则先根据公开状态计算每台电梯的六项候选特征，再用相同固定系数计算代价，选择可行且代价最低的电梯；空闲重定位使用Stay。规则定义在 [candidate-prior.json](../policies/candidate-prior.json)，它不需要训练或神经权重。

第二轮401模型使用相同候选和固定先验，另用神经网络学习调整量。候选策略的派梯分数为 `-固定候选代价 + 2 * tanh(网络输出)`，过滤不可行动作后选择最高分；网络因此有机会改变规则的选择。其候选残差分支使用MLP，训练配置中 `attention=false`，不能误认为当前首版Attention网络。原四目标奖励、事件时间折扣、PPO裁剪更新仍由其历史配置定义，`gamma=0.99`、`gae_lambda=0.95`。配置见 [ppo-s401.json](../configs/ppo-s401.json)，策略与权重身份见 [policies.json](../policies.json)。

兼容源码保留旧检查点加载和候选推理能力；本次没有增加训练算法。未保留第三轮模型、训练日志或结果，也不把兼容代码中存在的其他架构选项当作401实际启用的能力。离线推理时，应使用本目录的源码路径和归档模型根目录，并按策略索引选择规则或401模型，不能将其注册为当前默认模型。

保存前后24个真实公开状态的模型输出逐位一致，独立JSON规则与原模型中的float32先验完全一致；真实仿真同时核验了独立规则与关闭PPO调整的策略结果相同、两策略均完整服务。见[一致性核验](../../../reports/baseline-restore/reference-compatibility.json)。这些检查证明档案完整性，不证明PPO必然优于规则；旧实验数据见[对比报告](../reports/comparison.md)。
