# frontend

模型/训练/实验交互已恢复首版逻辑，默认`ppo-curriculum`；历史优化目录不在当前API索引中。保留散点图独立底边距、滚动图例及较高图表容器，避免等待/距离与图例重叠；这些仅影响显示，不改变模型/指标。

日常操作者请先阅读[零基础前端使用手册](用户使用手册.md)：包含历史正式对比、新建同流实验、实时控制、指标/图表解释、导出、训练查看与常见问题。文中按现有页面标签和真实历史实验名称编写。

React页面分为Configuration、Simulation、Evaluation、Training，通用API、useRun状态、SVG与Chart组件独立。所有业务数据来自真实API；前端不选择路线、不完成乘客、不计算权威指标。

useRun结合WebSocket与500ms REST校准，按run隔离、序列去旧、指数退避重连，卸载释放socket/计时器/请求；终态从REST补查。SVG只在有效服务器相邻运动段内插值，暂停/断线/过期停止，30层可滚动。图表实例按生命周期释放，趋势和日志有上限。

Vite开发代理/api和/ws至8000；生产build由FastAPI同源托管。配置有显式单位，后台独立校验；完整JSON支持分段、burst与奖励等高级参数。评价默认沿用配置页设置，跨trace汇总保留不完整提示，少量页面实验不冒充正式结论。训练启动使用CLI，页面读取真实日志。

运行中趋势保留最近500个权威快照；终态从timeseries接口补回真实归档的≤500点并保留首尾，避免最快模式只收到一次推送而无曲线。单有效点显示符号，未接到样本保留null。终态乘客详情也停止周期轮询，切换run取消尚未结束的趋势请求。
