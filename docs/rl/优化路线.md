# 当前PPO的后续优化路线

这是基于现有数据提出的下一轮研发计划，尚未把这些建议作为新算法实施或宣称已改善效果。当前模型、物理语义、原始测试数据和旧报告继续保留。

## 先统一“更好”的定义

原方案的研究目标是中负载相对ETA：平均等待降低至少5%，P95和距离增加均不超过5%，且乘客服务完整。当前距离增加59.74%，有明显缺口；全标准场景下，PPO平均等待还比轮询多18.97%。因此下一轮同时报告ETA、ETA-Zone、轮询三个参照，不以只超过ETA证明全面胜出。

已公开的9001–9020测试结果现在用于诊断。利用这些反馈调参后，应另外冻结未曾用于训练/调参的新测试流；原矩阵保留作历史回归。训练、验证、最终测试各用独立seed，建筑held-out仍保留；不在最终测试上选模型、选奖励或选最有利的seed。

## 优先级1：查清派梯和选模的问题

当前标准矩阵seed101的重定位距离为0，但总距离仍为198.58层，ETA为139.96层。其空载/载客距离44.42/154.17层也都高于ETA的16.16/123.80层。距离增长不能全部归因于重定位，应先分解：空载接人、载客绕行、重定位、开关门和启动次数。

复用decisions.jsonl和passengers.csv，按交通/负载/建筑汇总：各梯派单占比、与可行最小ETA的差值、单位乘客距离、当前等候/最长等待、重定位动作分布及后续是否服务乘客。观察固定argmax是否长期偏向某一梯；这是待验证假设，不能仅凭汇总断定原因。保留确定性推理，随机采样只能作为单独命名的研究变体，不能静默改变原策略语义。

当前validate_policy最多验证3个固定基础场景，按完整服务后的加权成本选best。正式训练同时做了楼层、梯数、容量、速度、模式和负载的域随机化；问题不是“完全没有随机化”，而是验证覆盖比训练和正式评价窄。扩展固定验证集，覆盖五模式、三负载和多建筑，仍排除held-out；同时报告距离/P95/完成率，并记录新验证配置版本。按同样验证规则重新比较所有模型，避免只选低标量成本却距离很大的checkpoint。

**本阶段交付**：派梯/距离归因表、完整验证场景清单、各checkpoint四目标曲线。先确认失败来自策略与训练，不通过改物理、弱化基线或换测试流制造提升。

## 优先级2：让优化目标与验收目标一致

先在独立验证集试少量预先固定的能耗权重，例如现值的2倍/4倍/8倍，观察等待—距离的权衡；一次只改变一个因素。能耗代理同时包含距离、门和启动成本，提高其权重不等同于直接约束距离。分别保留原始分项，确认实际数量级及有效梯度，再决定参数。

选模先要求服务完整，再要求距离/P95达到验证容差；满足后按平均等待排序。没有满足约束的模型就明确记为“无可行模型”，同时保留最接近目标的Pareto前沿供研究，不改成“已通过”。

若权重扫描仍不能稳定兼顾目标，可研究显式距离约束，例如在固定验证分布上要求`E[Distance_PPO] ≤ 1.05×E[Distance_ETA]`；训练可使用独立距离critic和自适应惩罚乘子，或评估约束策略优化方法。PPO是策略优化方法，其更新裁剪并不直接保证电梯距离约束；[PPO原论文](https://arxiv.org/abs/1707.06347)与[约束策略优化原论文](https://arxiv.org/abs/1705.10528)提供方法背景。这是候选研究方向，不能声称套用后就保证每一条Trace满足约束，仍须逐场景/尾部/压力复核。

**本阶段交付**：同验证流的权重扫描表、可行性判定与等待—距离曲线；改变奖励/模型结构须升级版本、重训并独立注册。

## 优先级3：用经典算法帮助学习

可以增加一个明确命名的新模型：先学习ETA或ETA-Zone在公开DecisionView上的动作，再用PPO微调；或用ETA分数作初始偏好，让网络学习修正。模仿数据只来自训练场景、当时公开状态与合法候选，不读取未来Trace；基础策略不能通过测试集选择。

若增加“PPO建议偏离过大时采用ETA”的运行规则，应注册为独立混合控制器并单独报告，记录覆盖次数；不能把混合结果标成原纯PPO。模仿/混合都需要真正实现、测试和评价，目前交付系统没有这些优化。

无Attention变体在单seed消融中平均等待19.61秒，完整seed101为30.51秒，这是“简化模型值得复查”的证据，不足以得出Attention无用。把相同输入、相同预算的有/无Attention扩到至少3个训练seed，用独立验证选择。先在5–8层、2–3梯、单模式稳定超过基线，再扩大域随机化难度。

**本阶段交付**：纯PPO/简化PPO/模仿初始化/混合策略的独立标识和同流结果，避免比较对象不清。

## 优先级4：单独验证重定位是否有价值

seed101强制Stay与原模型在300条消融Trace上完全相同，说明这些测试没有体现它的重定位收益。seed202/303平均重定位距离24.29/28.65层，因此重定位分支并非所有模型都不工作。

设计更长、未来客流确有规律但只能用历史观察预测的训练场景，覆盖低流量空闲段和下一波高峰；分别比较无重定位、ETA-Zone重定位、学习重定位。先固定Dispatch再研究Reposition的奖励归因，记录空驶代价、后续接人收益、冷却和被抢占比例。现有初始全部大堂、120秒到达窗口可能不足以呈现长期收益，这是待验证的场景假设。

## 优先级5：延长预算和暴露窗口

在前述诊断后，将同一候选配置逐档增加到20万、80万、200万决策，至少3个独立训练seed；先看固定验证是否改善再扩大预算。现有full.yaml只把T3预算改成200万，其到达窗口仍为120秒，不会自动把验证覆盖、距离约束或长窗口实验一起补齐。

新增1800秒及更长到达窗口，所有参照使用相同流、统一drain和相同初始状态；压力实验单列，不能把未完成乘客删掉。若研究稳定运行，可另设明确定义的热身与计分窗口，升级统计口径并保留原结果，不能暗中更改cohort。

短跑耗时不能线性保证百万决策耗时，因为环境负载和路由复杂度会变化；先实测候选配置的20万预算，再估算资源与后续预算。

## 下一轮完成标准

| 必须记录 | 判断方法 |
|---|---|
| 工程正确 | 物理守恒、特征无泄漏、动作合法、双头梯度、完整回归、真实前端加载 |
| 服务可靠 | 常规场景全服务；压力未完成/等待下界逐项披露 |
| 研究目标 | 预先冻结中负载：平均等待≤ETA的95%、P95≤105%、距离≤105%、服务完整；记录逐场景及汇总 |
| 三基线对比 | 同时报告ETA、ETA-Zone、轮询，避免只超过较弱的一项 |
| 不确定性 | 至少3独立模型seed，至少20条配对Trace；模型seed和Trace分层区间，不用“最好seed”代替总体 |
| 可复现 | 新配置/版本/Trace哈希、训练曲线、checkpoint、原始CSV和选模记录完整 |

少量seed的均值容易产生不稳定结论，报告区间与跨seed差异的依据可参见[强化学习评估原论文](https://arxiv.org/abs/2108.13264)。本项目建议的执行顺序是：**诊断/扩大验证 → 对齐距离目标 → 对照简化与基线引导 → 重定位专项 → 扩预算与长窗口 → 新盲测**。每步依据真实结果决定是否进入更昂贵的训练。
