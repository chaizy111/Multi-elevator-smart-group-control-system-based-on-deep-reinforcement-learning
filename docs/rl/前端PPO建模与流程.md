# 提交版PPO建模与流程

前端默认PPO为ppo-consequences-s801-n200000，获选143360步。它使用公开电梯、路线、楼层队列、请求和全局特征，另加入逐梯六项插单后果；只读取已到达任务。

路线与电梯共享编码后经过两层4头Attention。128维电梯编码、96维上下文及6维后果组成230维派梯输入，经128单元MLP输出每梯分数。重定位头及critic保留原结构，共427399参数，新增768。由原派梯输入224维补6列零权重迁移，再通过真实PPO学习。

最多13动作：派梯0—7，Stay为8，四区域为9—12。网络logits经合法mask后取argmax。没有固定候选系数、规则残差、教师动作或兜底。

训练为：环境推进到决策→采样动作→事件仿真给出区间成本及Δt→时间折扣和GAE→PPO裁剪目标、价值及熵损失→开发验证与检查点。奖励和共享优化器均不因提交整理改变。

135组开发输入上，单801等待/P95/距离为13.1399秒/33.0974秒/147.9481层；三seed为13.7975秒/36.4108秒/153.5728层。原PPO等待24.4030秒，固定规则11.3546秒。单模型与三seed须分别标注，开发数据不是盲测。
